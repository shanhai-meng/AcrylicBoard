# 亚克力记录板（AcrylicBoard）

一块铺在桌面壁纸上的「全透明亚克力板」。文字与图片直接浮在壁纸上、垫在桌面图标之下、处于所有前台应用窗口之下——平时完全透明、点击穿透，绝不遮挡桌面操作；想记录时按一下全局快捷键即进入编辑模式，像在真实亚克力板上一样书写、修改、擦拭。

- 平台：macOS 13.0+（原生 AppKit，无第三方依赖）
- 语言：Swift 5.9+
- 形态：菜单栏应用（无 Dock 图标、不出现在 Cmd+Tab / Mission Control）
- 数据：`~/Library/Application Support/AcrylicBoard/`（`boards.json` + `images/`）

---

## 一、安装与运行

### 方式 A：一键打包脚本（推荐）

```bash
./build_app.sh            # 编译并组装 AcrylicBoard.app（不启动）
./build_app.sh --run      # 编译、组装并直接启动
./build_app.sh --install  # 编译、组装并复制到 /Applications
```

产物为项目根目录的 `AcrylicBoard.app`（ad-hoc 签名，可直接双击运行）。

### 方式 C：GitHub Release 直接下载（免编译，最省事）

macOS 13+（Apple Silicon）用户可直接到 GitHub Releases 页下载安装包：

- **下载地址**：https://github.com/shanhai-meng/AcrylicBoard/releases

双击 `AcrylicBoard-v1.0.6.dmg` → 把 `AcrylicBoard` 拖入「应用程序」即完成安装。若系统提示"无法验证开发者"，对应用右键 →「打开」一次即可（ad-hoc 签名的正常提示）。

### 方式 B：Swift 直接编译运行（开发调试）

```bash
swift run --package-path AcrylicBoard
```

首次启动后，菜单栏会出现记录板图标。平时板上没有内容时你几乎感受不到它的存在。

## 二、使用说明

### 编辑模式开关

| 操作 | 说明 |
| --- | --- |
| `⌘⇧B`（全局，任何应用内均可） | 进入 / 退出编辑模式 |
| 菜单栏图标 →「编辑模式」 | 同上 |
| `Esc`（编辑模式下） | 退出编辑模式 |
| 菜单栏图标 →「退出」 | 退出应用 |
| 菜单栏图标 →「检查更新…」 | 联网检查 GitHub 上是否有新版本（仅手动触发，平时不访问网络） |

进入编辑模式后，每一条内容变成一张「亚克力便签卡」浮层：文字可直接在卡内输入（支持中文输入法），图片卡片则显示圆角图片。

### 新建与导入

| 操作 | 说明 |
| --- | --- |
| 菜单栏 →「新建文字记录」或 `⌘⇧N` | 在屏幕中央新建一条空白文字 |
| 菜单栏 →「导入图片…」 | 从访达选择图片 |
| 菜单栏 →「粘贴图片」或 `⌘⇧V` | 粘贴剪贴板中的图片 |
| 拖放 | 直接把 Finder 里的图片文件拖到任意一张编辑卡上，会在落点附近新建一条图片 |

### 编辑单条内容

- **拖动**：按住卡片顶部圆点手柄，或用 ⌘ 之外的普通拖动即可移动整条（位置实时同步到壁纸层）。
- **缩放**：拖动卡片右下角手柄。文字卡调整宽度并自动重排换行；图片卡按原始比例整体缩放。
- **文字格式**：卡片上方的格式条可设置字体（含系统默认、苹方、楷体、宋体、黑体及西文字体）、字号、加粗 `B`、文字颜色。改动即所见即所得，退出编辑后同样呈现在壁纸上。
- **擦除单条**：点格式条右侧的 `✕`，或让卡片获得焦点后按 `⌘⌫`。
- **清空整板**：菜单栏 →「清空画布…」（需确认）。

### 持久化

所有内容在输入/移动/缩放/换样式后 0.4 秒内自动保存，无需手动存档。重启应用或重启电脑后原样恢复。

- **跨桌面 Space**：默认画布跟随所有桌面 Space（切到任一桌面都能看到同一块板）。取消菜单栏「在全部桌面 Space 显示画布」后改为**各桌面独立画布**：每个桌面各自保存独立内容（`boards.space-*.json`），互不显示对方；切到哪个桌面即显示哪块的独立画布，可即时在任意桌面新增/编辑。

> 提示：菜单栏 →「打开数据文件夹」可直接查看 `boards.json` 与 `images/`，方便备份或手工编辑。

## 三、开机自启

1. 先执行 `./build_app.sh --install`（或把 `AcrylicBoard.app` 手动放进「应用程序」文件夹）。
2. 菜单栏图标 →「开机自启」，勾选即生效，取消即关闭。

> `SMAppService.mainApp` 要求应用位于 `/Applications` 或系统认可的位置，否则注册会失败并提示。

## 五、已知限制

- **「点击壁纸显示桌面」手势**：macOS Sonoma 及以后，若系统启用了「点按壁纸显示桌面」，点击被透明层穿透到 Finder，可能触发显示桌面。这是系统级行为，应用无法阻止——可在「系统设置 → 桌面与程序坞」中关闭该手势，或改用触控板「五指散开」显示桌面。
- **仅主显示器**：MVP 阶段壁纸层与新建内容只落在主屏（`NSScreen.main`）。多显示器支持留待后续迭代。
- **图片格式**：拖入 / 导入支持 png / jpg / gif / heic / webp / tiff / bmp；入库前会统一降采样（最长边 ≤ 2560px），超大图显示为缩略图级别以控内存。
- **层级细节**：展示层窗口位于 Finder 桌面图标之下（`desktopIconWindow - 1` 层）。个别第三方壁纸工具若也抢占该层级，可能出现前后覆盖差异。

## 六、技术说明

- **一份数据 + 双窗口表现**：数据模型 `BoardStore` 是唯一数据源（JSON 原子落盘）；「壁纸层窗口」负责静态渲染，位于桌面层（点击穿透、不可聚焦、不可见键盘输入）；编辑时每条内容对应一个「浮层编辑窗」，承载真正的 `NSTextView` 输入（天然支持中文 IME 候选框定位）。
- **坐标体系**：内容矩形 `frame` 统一使用主屏全局坐标（与 `NSScreen.frame` 同坐标系），壁纸层与编辑层经同一套 `BoardLayout` 几何换算，保证「编辑所见 = 壁纸所得」。
- **窗口层级**：壁纸层 `level = CGWindowLevelForKey(.desktopIconWindow) - 1`，`ignoresMouseEvents = true`，Space 行为按设置取 `.canJoinAllSpaces`（默认开启，可在菜单栏关闭），不干扰任何桌面操作，也不出现在 Mission Control / Cmd+Tab。
- **全局快捷键**：Carbon `RegisterEventHotKey` 注册 `⌘⇧B / ⌘⇧N / ⌘⇧V`，无需「辅助功能」权限。
- **渲染一致性**：壁纸层与编辑层共用同一 `TextLayout`（`NSLayoutManager`）测量换行高度，保证字体行距、折行完全一致。
- **日志**：`os.Logger` 仅记录模式切换与持久化错误，不落盘任何内容隐私；写盘为原子替换，防止崩溃损坏 JSON。

## 七、自测清单（验收用）

打包并启动（`./build_app.sh --run`）后逐项核对：

- [ ] 启动后无 Dock 图标、不占 Cmd+Tab；菜单栏出现记录板图标。
- [ ] 板上有内容时：文字/图片可见于桌面壁纸上，且**位于所有窗口之下、桌面图标之下**；鼠标划过完全穿透，不影响桌面图标点击。
- [ ] 按 `⌘⇧B`：每条内容变为磨砂亚克力卡片；再按一次或按 `Esc` 全部收起并刷新壁纸层。
- [ ] 中文输入：卡片内用系统中文输入法输入一段文字，候选框定位正常、无乱码。
- [ ] 文字格式：改字体/字号/颜色/加粗后壁纸层立即呈现一致效果。
- [ ] 图片：`⌘⇧V` 粘贴截图、菜单导入、Finder 直接拖到卡片三种方式均能新增图片条目。
- [ ] 拖动手柄移动条目、右下角缩放（文字换行重排 / 图片等比缩放），壁纸层同步。
- [ ] `⌘⌫` 删除当前卡片、格式条 `✕` 删除、菜单「清空画布…」均生效。
- [ ] 重启应用后所有内容（文字样式与位置、图片）原样恢复。
- [ ] 切换多个桌面 Space：默认每个 Space 都可见且位于图标之下；取消菜单栏「在全部桌面 Space 显示画布」后只在当前桌面显示。
- [ ] 打开「开机自启」后重启电脑，应用随登录自动出现。
- [ ] 查看 `~/Library/Application Support/AcrylicBoard/boards.json`：内容完整、格式合法。
